# BreakTrail API

Node 22.13+ Express API with SQLite and Ollama. Read ../DEPLOYMENT.md for local and public setup.

Local mode defaults to PUBLIC_MODE=false and loopback access. Public mode requires HOST=0.0.0.0 and a private 64-character hex bearer token for preferences, plan generation, saved plans, history, state and deletion. Tokens are generated by the frontend per API endpoint and hashed on the backend to isolate database records. GET health, ollama/status and places are public. CORS allows only configured CLIENT_ORIGINS; private data requires the token regardless of Origin headers.

```bash
npm ci
npm test
npm start
```

Copy .env.example to .env for local use. Do not commit real environment files or SQLite databases. Public hosting needs durable DATABASE_PATH storage and a private Ollama endpoint reachable by the backend. The supplied root Compose file provides both.

The Postman collection is a local-mode reference; public private routes additionally need Authorization: Bearer YOUR_DEVICE_TOKEN. It is not a password-based account system. Keep device tokens private and export data before clearing browser storage.
